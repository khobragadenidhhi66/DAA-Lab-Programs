# Continuous Assessment 3 (CA3)

Welcome to the **CA3** directory of the Design and Analysis of Algorithms (DAA) Laboratory coursework.

## Purpose of this Directory
The **CA3** directory is designated for project presentations, viva demonstration materials, and multimedia deliverables required for internal academic assessment.

---

## Directory Contents

| Directory | Description | Status / Expected Content |
| :--- | :--- | :--- |
| [📁 PPT/](./PPT/) | Slides and presentation decks for CA3 evaluation. | Store your `.pptx` or `.pdf` presentation slides here. |
| [📁 Video/](./Video/) | Video recordings of algorithmic demonstrations and explanations. | Store your `.mp4` or `.mkv` demonstration recordings here. |

---

## Assessment Components & Guidelines

### 1. Presentation (PPT)
- **Topic:** Presentation on selected DAA topics, algorithm performance analysis, time/space complexity comparisons, and experimental benchmarks.
- **Accepted Formats:** `.pptx`, `.ppt`, `.pdf`.
- Refer to [PPT/README.md](./PPT/README.md) for slide deck guidelines and outline.

### 2. Video Demonstration
- **Topic:** Live execution and verbal explanation of the algorithms, CodeTantra submission walkthrough, or project presentation.
- **Accepted Formats:** `.mp4`, `.webm`, `.mkv`.
- Refer to [Video/README.md](./Video/README.md) for recording criteria and guidelines.

---

> [!NOTE]
> Per submission policies, no dummy or placeholder files are generated here. Please place your official `.pptx` presentations and `.mp4` video recordings directly into their respective folders prior to final evaluation.
