# CA3 Video Demonstration & Walkthrough

This directory is designated for hosting video demonstrations and project recordings for the **CA3 (Continuous Assessment 3)** evaluation in Design and Analysis of Algorithms (DAA).

---

## Purpose
- Store video recordings of live algorithm executions, code explanations, and viva presentations.
- Provide accessible demonstration files for evaluation and grading.

---

## Recommended Video Structure (5 to 10 Minutes)
1. **Introduction (1 min):** Student introduction, assignment topic, and problem statement.
2. **Algorithm & Logic Explanation (2-3 min):** Walkthrough of the algorithm logic, design paradigm, and edge cases.
3. **Live Code Demonstration (2-3 min):**
   - Compiling the code in terminal (`gcc`).
   - Running test cases with normal, edge-case, and boundary inputs.
   - Showing step-by-step intermediate and final outputs.
4. **Complexity & Discussion (1 min):** Summary of time/space complexity and Q&A points.

---

## Technical Specifications
- **Recommended Video Formats:** `.mp4` (H.264 / AAC), `.webm`, `.mkv`
- **Resolution:** 1080p (1920x1080) or 720p (1280x720) at 30/60 fps.
- **Audio Quality:** Clear narration using an external microphone or headset with minimal background noise.
- **Recommended Screen Recorders:**
  - OBS Studio (Open Broadcaster Software)
  - Windows Xbox Game Bar (`Win + G` or `Win + Alt + R`)
  - Loom / ShareX
- **File Naming Convention:**
  - `DAA_CA3_Demo_<RollNumber>_<AlgorithmName>.mp4`
  - Example: `DAA_CA3_Demo_21BCS101_Bellman_Ford.mp4`
